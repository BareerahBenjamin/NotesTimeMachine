# V2.0 UI / UX 与交互动效交付

日期：2026-10-19。实际代码已写入当前工作区，未发布到线上。保留 HTML、CSS、原生 ES Modules；Cloudflare 业务代码和 API 协议未改动。

## UI 改版

首页改为数字文学展览入口：双栏编辑式标题、每日诗笺、精选馆藏、阅读流程，以及本地 SVG 淡墨山水。保留语义检索和作者入口。书架改为有书名、作者、朝代、章节信息的藏品卡片，并新增独立作品档案入口。阅读器桌面并排展示原文与注疏，移动端按阅读顺序展开，始终显示所选原文引句。日间使用宣纸、墨绿、朱砂，夜读使用深墨绿纸面。

## 动效与关键实现

- 首页三层标题内容依次进入：320ms / 60ms stagger。文学内容滚动进入：IntersectionObserver 一次触发，随后 unobserve。
- 山水仅随用户滚动轻微移动：passive scroll + requestAnimationFrame 合并，最大24px；移动端和 reduce 关闭。
- 原文选择用180ms opacity 聚焦；文字不再因 hover 改变 padding 而跳动。
- 注疏面板以280ms transform/opacity 进入、180ms opacity 退出；取消原 max-height 动画和裁切限制。退出动画有版本保护，快速重开不会被旧动画隐藏。
- 时间线使用 scaleY 延伸；节点按序进入，选择节点切换到对应注疏；保留原朝代筛选与全部重置，补充空态。面板与节点共享每视图最多3个入场的预算，更多节点直接显示。
- 书籍在支持 hover 的设备上抬升4px，触屏按下给予反馈；详情使用平滑进入，支持 Escape、Tab 焦点约束和返回触发按钮。
- 全部 JS 动画通过 `js/motion/index.js` 调用，不读取业务数据、不发 API 请求。运行时 reduce 偏好变更会取消动画；CSS reduce 关闭动画、过渡和平滑滚动。

官方参考及适配说明见 [设计规范](V2-DESIGN.md)。原生配方参考 fade-in-up、scroll-reveal、card-lift-hover；未增加动画依赖。

## 测试结果

浏览器回归：**13 / 13 通过**。

1. 17本书的独立阅读入口与详情按钮。
2. 离线示例原文与两条预置注疏。
3. 节点选择只显示对应注疏且不改变原文关联。
4. 朝代筛选空态及全部重置。
5. 面板收起后立即重开，旧动画不会隐藏新面板。
6. JS reduce 偏好降级后仍可打开/关闭面板。
7. 快速选句时旧 AI 响应不会覆盖新句。
8. 旧段落注疏请求不会打开过期内容。
9. 关闭后返回的 AI 响应不会更新面板。
10. 模拟在线章节导航、上一章/下一章及边界禁用。
11. 模拟在线语义检索的双入口结果与跳转数据。
12. 搜索结果跳转到正确章节并选中原文。
13. 无注疏段落的空态。

浏览器人工验证：三原型重播/展开/切换；桌面1280px首页、17本书架、作者简介、浅色/夜读；键盘 Enter 选段、Tab 约束、Escape 关闭和返回原文/详情触发按钮；搜索空输入与服务不可用提示；移动菜单进入书架、选书、注疏展开与自动定位。

响应式：浏览器 viewport override 没有实际改变当前标签页尺寸，改用固定宽度 iframe 的真实布局引擎验证。320 / 390 / 768px 阅读布局的 body 宽分别314 / 384 / 762px（其余为滚动条），scrollWidth 与 body 宽一致，无横向溢出。390px 首页和书架也验证无横向溢出。该方法不代表手机真机或触控性能验收。

静态检查：所有改动 JS 文件与回归脚本 `node --check` 通过；HTML 标签嵌套与 ID 唯一性通过；`git diff --check` 通过。

性能检查：新增视觉/动效/可访问性层未压缩合计约25.5KB，运行依赖新增0项。动效使用 transform/opacity；无持续装饰循环；不再使用原2.3MB背景图作为首页背景；保留现有字体和站标。未做 Lighthouse、真实帧率或手机硬件性能测量，因此不宣称已经达到特定分数或60fps。
