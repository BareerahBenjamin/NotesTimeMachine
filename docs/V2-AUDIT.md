# V2 前端验收与修复记录

日期：2026-10-19。范围：现有 HTML / CSS / 原生 JavaScript；没有新增业务功能、迁移框架、修改 `cf-worker/src`、提交或推送分支。

## 结论与边界

已修复本轮识别的前端 P0 / P1 问题，并实际运行浏览器、真实 Worker 接口和隔离模块测试。不能据此宣称整站所有测试通过：AI 事实准确性、远端 D1 偶发失败、线上 CWV、真机触屏及长期内存变化仍有未解决或未验证项。

### A. 隔离模块测试：20 / 20

浏览器实际打开 `tests/regression.html` 并点击运行。该页使用受控响应，只验证前端模块，不作为真实业务接口通过证据。

覆盖：17 书目入口保留、独立演示模块、节点关联、时代筛选空态、关闭立即重开、减弱动态效果 JS 分支、旧 AI/注疏响应失效、关闭后失效、章节边界、搜索入口及跳转、同书并发加载、连续搜索和去重、切书清空旧句、安全 HTML、重复展开不重播、motion 初始化/销毁、真实来源导航、无注疏空态。

新增加的搜索竞态测试曾因夹具缺少 `classic_id` 失败；补齐测试字段后最终 20 / 20。没有通过修改生产结果掩盖测试失败。

证据：[unit-results.txt](audit-evidence/unit-results.txt)。真实读取见 [worker-read-results.json](audit-evidence/worker-read-results.json)，账号/写入读回及清理见 [live-account-results.json](audit-evidence/live-account-results.json)。

### B. 真实 Worker 读取/AI 回归：12 项

执行 `python3 tests/worker-smoke.py`：健康、17 部馆藏、漱玉词 12 章、3 段原文、6 条注疏、5 个社区分类、帖子列表、语义搜索、整体 AI 分析、单条 AI 解读、空搜索 400、未登录保存 401，最终均符合预期 HTTP 状态。

本次语义搜索约 4.04s，AI 分析约 2.34s，单条解读约 2.46s。这是本地代理与远端绑定条件下的单次观测，不是线上性能结论。HTTP 成功没有被当成 AI 内容正确。

### E. 失败与恢复

实际停止本任务启动的独立本地 Worker 进程组：原文显示加载失败/重新加载，搜索明确连接失败，社区明确分类和帖子加载失败；未显示演示原文或假帖子。随后恢复 Worker，真实阅读重新加载成功。另一次断开后实际点击“重新加载社区”，恢复 6 个分类按钮（含全部）及原有 2 条帖子；测试话题清理后没有留下额外帖子。云端部署没有停止或变更。

### F. 静态及性能检查

- 19 个 JS 文件实际执行 Node 语法检查；HTML ID 无重复；相对 JS import、HTML 资源、CSS url 依赖均存在；`git diff --check` 通过。
- `git diff -- cf-worker/src` 为空；未执行提交/推送。
- 前端加载诊断未记录应用 error/unhandledrejection；图标实际加载完成；字体集合状态 loaded，最终字体错误列表为空（[final-diagnostics.json](audit-evidence/final-diagnostics.json)）。故障测试的预期网络错误与正常加载分开判断。
- 工具操作 iframe 时曾产生一条无来源的 MutationObserver 错误；正常页面诊断未捕获对应应用错误，未将它归因为产品故障，也未把浏览器日志全称为零错误。
- 图标实际请求从约 1,948KB 降为约 14KB，原大背景图未被加载。
- JS scroll 监听与逐帧视差移除；支持时使用有限 CSS ScrollTimeline，其他浏览器静态回退。无与阅读无关的无限动画；动画对象结束/取消后清理；关闭/换句取消 AI 请求。
- 共用色板的正文、次要文字、主要填充按钮均做数学对比度检查，详见 [palette-contrast.json](audit-evidence/palette-contrast.json)。这不等于整站所有透明层/徽标完成自动 WCAG 审计。

| 指标 | 实际观测 | 限制 |
| --- | --- | --- |
| LCP | 本地 iframe 重新载入约 188ms | 字体/第三方资源可能命中缓存，不是严格冷缓存或线上数据 |
| 布局偏移 | 同次首页观察累计约 0.0010；一次跨页面流程累计约 0.0422 | 诊断记录为偏移总和，未实现标准 CLS 会话窗口算法，不冒充正式 CLS |
| 交互事件时长 | 观察到的最大事件时长约 80ms | 不是 INP 计算，也不是长时间/真实用户样本 |
| INP / 标准 CLS / 完整 Trace | 未验证 | 当前没有 Chrome DevTools MCP；没有输出 Lighthouse 分数或线上 CWV 通过结论 |

见 [cold-diagnostics.json](audit-evidence/cold-diagnostics.json)、[flow-diagnostics.json](audit-evidence/flow-diagnostics.json)、[static-checks.json](audit-evidence/static-checks.json)。`cold` 文件名表示该次页面重新载入记录，不代表清空浏览器缓存。
