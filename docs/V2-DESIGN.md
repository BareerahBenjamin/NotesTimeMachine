# 前端设计与排版

首页以宣纸底色、墨绿、朱砂和长卷式布局呈现馆藏。阅读器保留中文系统衬线字体，导航和部分控件使用系统无衬线字体。夜读配色由同一组语义色变量提供。 [基础变量](../css/variables.css) · [站点主题](../css/v2.css)

首页展签与馆藏卡片参考 `YXY-UI-49.zip` 中的暖纸展台和展品卡片。主导航与注疏选择借鉴分段控件的选中反馈，分别使用 `aria-current` 和 `aria-pressed` 标记状态。窄屏菜单保持纵向排列，注疏选项可换行。 [导航样式](../css/header.css)

## 文字层级

| 用途 | 默认字号 |
| --- | --- |
| 内页主标题 | 28–32px |
| 区块标题、卡片标题 | 24px、20px |
| 正文和重点正文 | 16px、18px |
| 古籍原文 | 20px，行高 2.1 |
| 按钮、表单、导航 | 16px 起 |
| 来源摘要、状态和辅助标签 | 14px 起 |

字号使用 `rem`，页面主标题随视口在范围内变化。首页展陈标题使用独立的大字号。原文和注疏在宽屏并排，在窄屏顺序排列。窄屏布局允许操作组、帖子信息和个人页统计换行。 [基础排版](../css/reset.css) · [阅读器](../css/reader.css)

## 动效与验证

`js/motion/` 和 `css/motion.css` 提供页面进入、原文聚焦和注疏切换动效。系统开启减少动态效果时使用即时状态切换。独立原型可用来检查动效和静态回退。 [动效原型](../prototypes/motion.html) · [浏览器回归](../tests/browser-activation.cjs)
