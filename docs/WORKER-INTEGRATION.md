新增开发脚本：
- `scripts/dev-proxy.mjs`：设置仅作用于当前开发进程的代理环境，启动 Wrangler，监听127.0.0.1:8787。
- `scripts/dev-proxy.cjs`：为本地 Miniflare 的 outboundService 添加 Node fetch 传输桥接，让 workerd 使用当前 HTTP(S)_PROXY。保留 TLS 校验，不修改绑定、凭据或业务源码。

原因：普通 `wrangler dev` 的 Node 控制连接及 workerd 出站连接未完整使用当前系统代理。仅启用 Node `--use-env-proxy` 可启动服务，但 R2/D1 仍在约75秒后失败；加入开发侧出站桥接后全部真实接口正常。

该预加载脚本适配的是 Miniflare 开发选项，使用了导出类包装，属于当前网络环境的开发兼容方案；Wrangler/Miniflare 升级后需回归。已验证版本：Node22.22.3，Wrangler4.151.1，Miniflare5.20261012.1-beta。没有代理环境变量时启动器不加载桥接。不用于线上 Worker。
